# 快捷回复（Answer Choice）

> 需要你拿主意时，把选项挂到输入框上方：点一下，答案就回到对话里。

Agent 在需要你拍板的时候调用 `answer_choice`，选项面板直接出现在输入框上方，不打断正在进行的工具调用。你点一个、或者自己写一个，选择作为一条消息回到对话，Agent 接着往下做。

## 功能

- **选项挂到输入框上方**：点一下就走，也能自己写一个答案，快捷阅读与回复
- **单选 / 多选**：由调用时指定；多选在顶栏显示已选数量，再按确认
- **自定义答案**：允不允许由调用时指定
- **可折叠**：顶栏整条可点，把面板收成一条，收起时只剩标题和展开箭头
- **两种形态**：弹窗（输入框上方）与卡片（对话里），界面观感一致
- **自动收起**：你在会话里发出下一条消息时，还敞开的面板自己收起
- **模型工具 `answer_choice`**：Agent 侧无需额外配置

## 用法

- **弹窗**：默认形态。Agent 调用后，面板出现在输入框上方，点选项或按「确认」
- **卡片**：在设置里切换。选项以卡片形式出现在对话里
- **设置**：`设置 → 快捷回复`，选择用哪种形态（切换后需重启 HanaAgent 生效）

## 安装

1. 从 [Releases](https://github.com/youyongdemao/HanaAgent-answer-choice/releases) 下载 `answer-choice-v*.zip`
2. 在 HanaAgent「设置 → 扩展」中安装
3. **权限要逐项开**：装完后去 `设置 → 应用 → 应用能力`，把下面这些打开

| 能力 | 用途 |
|------|------|
| `app/tools.expose-to-model` | 向模型暴露 `answer_choice` 工具 |
| `app/input.panels` | 往输入框上方渲染选择面板 |
| `app/session.start-turn` | 把选择作为一条消息投回会话 |
| `app/sessions.read` | 读会话信息，把会话路径换成面板要的 `sessionId` |
| `app/sessions.manage` | 目标会话不属于本 App 时的跨归属投递 |
| `app/hooks.session-input` | 用户一提交输入就收起还敞开的面板 |
| `app/hooks.agent-before-start` | 每轮往系统提示注入调用规则 |

两个钩子最关键。不打开，注入规则不生效，整个 App 等于没装。

## 设置

| 项 | 说明 | 默认 |
|----|------|------|
| 提问形态 | 弹窗（输入框上方）或卡片（对话里） | 弹窗 |

## 已知限制

- 面板不阻塞工具调用：Agent 拿到的是「已挂出」回执，你点完它才会收到新消息
- 每个会话同时最多 32 个面板，整个宿主 512 个
- App 重载后工具 RPC 通道可能不会自动重建，需要刷新界面或重启宿主
- 卡片形态的卡片内容由本 App 现场生成，模型偶尔改动会让它渲染失败，重问一次即可
