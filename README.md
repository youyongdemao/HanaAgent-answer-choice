# 选项提问（Ask Choice）

让 Agent 在需要你拿主意时，把几个选项直接列在输入框上方：点一个就行，也能自己写一个答案。

## 功能

- Agent 调用 `ask_choice`，选项面板出现在输入框上方，人点完再继续
- 单选或双选由调用时指定，允不允许自定义答案也由调用时指定
- 放弃、超时、面板被关闭都会明确回到 Agent，不会被当成空答案混过去
- 面板是自定义页面（主题跟随宿主），确认与拒绝按钮由宿主绘制

## 用法

Agent 侧无需额外说明，工具描述里已经写清了适用场景。参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `question` | 是 | 要问用户的问题，一句话说清让他定什么 |
| `options` | 是 | 2–8 个候选项，简短短语，自动去重与截断 |
| `allow_custom` | 否 | 是否允许用户自己写答案，默认允许 |
| `multi` | 否 | 是否多选，默认单选 |
| `title` | 否 | 面板标题，省略时用「请选择」 |

返回给模型的是 `用户的选择：<内容>`；多选用「、」连接，自定义答案就是原文。

## 结构

```
manifest.json        清单（tools + input.panels 能力）
index.js             工具 ask_choice：挡在 execute 里等用户回答
ui/choice.html       输入框上方的选择页
ui/assets/choice.js  渲染选项 + onSubmit 交回选择
sdk/                 打包随附的 App SDK
```

## 依赖

两件事必须由人来做，App 自己申请不了：

1. 在安全设置里授予 `app/input.panels`（等于允许它往输入框上方渲染自己的界面）
2. 在目标 Agent 上启用本 App

## 已知限制

- 一次提问最长等 10 分钟（宿主上限），超时按 timeout 返回
- 确认 / 拒绝 / 关闭由宿主放在页面之外，页面无法代替用户点头
- 每个会话同时最多 32 个面板，整个宿主 512 个（宿主限制）
