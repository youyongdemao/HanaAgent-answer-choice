# 快捷回复

让 Agent 在需要你拿主意时，把几个选项挂到卡片上：点一个就行，也能自己写一个答案，从而快捷阅读与回复

## 功能

- Agent 调用 `ask_choice`，选项面板出现在输入框上方，**不阻塞**工具调用
- 单选或多选由调用时指定，允不允许自定义答案也由调用时指定
- 单选点一下就走；多选在顶栏显示已选数量，再按确认
- 顶栏整条可点，能把面板收成一条（收起时只剩标题和展开箭头）
- 你点「确认」或「跳过」后，选择会作为一条消息回到对话，Agent 接着往下做
- 你在会话里发出下一条消息时，还敞开的面板自己收起
- 面板是自定义页面（主题跟随宿主），确认按钮由面板自己绘制

## 为什么不用宿主的阻塞式提问

宿主对 App 工具执行设了 **30 秒硬超时**（`app-host-entry.js` 里 `APP_HOST_RPC_TIMEOUT_MS = 30000`，
工具调用走 `callback.tools.execute` 时用的就是这个默认值）。而 App 内部声明的等待上限是十分钟，
两者对不上：只要用户 30 秒内没答完，工具就被判超时失败。

所以本 App 走两段式：工具挂上面板立刻返回；用户在面板上点完，面板把选择 POST 回 App 的 `/submit`
路由，App 再用 `session:send` 把选择投回会话，唤醒 Agent。

## 用法

Agent 侧无需额外说明，工具描述里已经写清了适用场景。参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `question` | 是 | 要问用户的问题，一句话说清让他定什么 |
| `options` | 是 | 2–8 个候选项，简短短语，自动去重与截断 |
| `allow_custom` | 否 | 是否允许用户自己写答案，默认允许 |
| `multi` | 否 | 是否多选，默认单选 |
| `title` | 否 | 面板标题，省略时用「需要你定一下」 |

回到会话的消息形如 `用户的选择：<内容>`；多选用「、」连接，自定义答案就是原文，跳过则是一条
`（用户跳过了这次选择）`。

## 需要的能力

| 能力 | 用途 |
|------|------|
| `app/input.panels` | 往输入框上方渲染自己的面板 |
| `app/session.start-turn` | 往会话里投一条会进入模型的消息（发回合） |
| `app/sessions.read` | 读会话信息，把会话路径换成面板要的 `sessionId` |
| `app/sessions.manage` | 目标会话不属于本 App 时的跨归属投递（`scope: "all"`） |
| `app/hooks.session-input` | 用户一提交输入就收起还敞开的面板 |

这些都要用户在 设置 → 应用 → 应用能力 里显式开启，默认关闭。

## 结构

```
manifest.json        清单（tools + input.panels + session.start-turn）
index.js             工具 ask_choice：show 挂面板后立即返回；/submit 路由把选择投回会话
ui/choice.html       输入框上方的选择页
ui/assets/choice.js  渲染选项 + 自绘确认按钮，POST 到 /submit
sdk/                 打包随附的 App SDK
```

## 已知限制

- 面板不阻塞工具调用：Agent 拿到的是「已挂出」回执，你点完它才会收到新消息
- 宿主自带的确认按钮在非阻塞面板上不生效（它要求面板带 `confirmId`），所以确认按钮由面板自绘
- 每个会话同时最多 32 个面板，整个宿主 512 个（宿主限制）
- App 重载后工具 RPC 通道可能不会自动重建，需要刷新界面或重启宿主
